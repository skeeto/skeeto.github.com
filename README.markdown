This is my [personal blog](https://nullprogram.com/), hosted on GitHub
Pages. The site is generated by ssg, a small static site generator in
`_ssg/` written in C++ (no standard library), and deployed by GitHub
Actions (`.github/workflows/pages.yml`).

    $ cmake -S _ssg -B _ssg/build
    $ cmake --build _ssg/build
    $ _ssg/build/ssg              # writes _site/
    $ _ssg/build/ssg -w           # rebuild whenever the source changes
    $ _ssg/build/ssg -n draft.md  # publish a draft into _posts/

Posts are Markdown files in `_posts/` named `YYYY-MM-DD-slug.markdown`,
in the subset of kramdown's dialect that ssg implements. Tag pages and
feeds are generated from the posts' front matter. Other files are
published as-is, except those starting with `_` or `.`.
